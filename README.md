# 朱老師觀察池 Dashboard V4.0（方案 B）

內含 `index.html`、盤後行情更新程式 `scripts/update.py`、GitHub Actions 排程，以及舊版 `legacy_v3.html` 備份。保留 V3.0 早期訊號、V3.1 品質與風報比、V3.1.1 空頭破底防呆；三策略分開處理。

## 立刻開啟（離線介面）

直接開啟 `index.html`：可查看和編輯觀察池、匯入舊版觀察池 JSON、手動載入 `market.json`；**沒有行情資料不會出現真實 K 線或正式買點**。`file://` 開啟時，瀏覽器通常禁止讀取相對路徑的 JSON，因此若已產出資料，按「手動載入 market.json」即可。

## 本機啟動與更新（Python 3.9+）

在本資料夾終端機執行：

```bash
python scripts/update.py
python -m http.server 8000
```

打開 http://localhost:8000 。按「↻ 更新行情」可重新**讀取已存在的** `data/market.json`，不會主動在瀏覽器執行行情抓取程式。需每天另行跑 `python scripts/update.py` 才能取得新資料。

更新程式使用 Yahoo Finance 的非官方公開 chart 端點，依股票代號先查 `.TW`、失敗再查 `.TWO`，每日 OHLCV 約一年，保留資料來源、產出時間與抓取錯誤。此來源可能阻擋請求、延遲、出現權息調整差異，**不是交易所官方結算認證，也不保證能成功**。失敗時可沿用舊行情但會標示 `carryForward`，舊資料不可當最新收盤。

## GitHub Actions 自動化（推薦）

1. 建立自己的 GitHub 儲存庫，將 ZIP 解壓後所有檔案（包含 `.github/workflows/daily.yml`）上傳至儲存庫根目錄。保留 `data/` 目錄（裡面有 `.gitkeep`）。
2. GitHub 儲存庫 **Settings → Actions → General → Workflow permissions** 設定為 **Read and write permissions**，才可讓工作流程推送 `data/market.json`。
3. 開啟 **Actions → Update Taiwan stock daily candles → Run workflow** 手動首次執行。查看日誌有無成功生成 `data/market.json`；若資料供應商封鎖，需替換為合法授權行情 API。
4. 到 **Settings → Pages → Build and deployment** 選 **Deploy from a branch**、分支 `main`、資料夾 `/ (root)`；待網站發布後以 Pages 網址開啟。第一次設定 Pages 需確認專案可公開，**不要將私人持股、帳號、API token 提交到公開儲存庫**。
5. 排程設為週一至週五 **台灣時間 18:30**（UTC 10:30），台股休市日和資料源延遲會造成最近資料日落後。GitHub Actions 排程有機會延後或略過，請以 Dashboard 實際「資料日期／更新時間」為準。
6. 若你要追蹤更多標的，先在 `scripts/update.py` 的 `WATCH` 加入股票代號、名稱與類型；再至頁面「新增標的」補入同一代號及對應交易劇本。

注意：本專案瀏覽器端編輯的觀察池用 localStorage 保存在**當下瀏覽器／網站網域**；換電腦、從 file:// 改成 GitHub Pages，資料不會自動跟著走。先匯出 JSON 再於新網址匯入。更新程式更新市場資料，不會覆蓋你個人的觀察池設定。

## 規則與限制

- 短波段的 10 條客觀檢核：趨勢、人工觀察區確認、止跌、底底高、KD 的 K 值向上、價 K 同步、合格紅 K、突破前日高或站回20MA、放量與實體、完整交易日；**10/10 不是勝率**。閾值是可調整的操作化近似：例如放量定義 20 日均量的 1.15 倍、紅 K 實體占振幅 ≥ 35%，**並非聲稱朱老師課程逐字規定了這兩個數值**。
- V3.1 風險報酬檢核需要交易劇本中的「停損價」「目標價」「最低要求風報比」；未設定時不給正式候選綠燈。請勿把推算出的停損目標當確定值。回後首次轉強和正式突破是不同階段。
- V3.1.1：下降 20MA 以下且高低點下移、空頭或仍破底一律先警戒，反彈紅 K 不代表正式買點。使用 5+5 根局部高低點作程式代理判斷，仍須人工核對波段級別與型態。
- 長波段只列中長期趨勢及支撐結構；ETF 分批成本帶／比重須手動設定，不使用短波段 10/10 條件。
- KD 使用 9 日 RSV，初值 50、遞迴 3 平滑（9,3,3），均線使用簡單移動平均；提供的數據可能與券商使用的還原權息或初始化不同。圖表用瀏覽器 Canvas 自繪，可拖曳、縮放和十字線。
- 「完整交易日」以台灣時間 13:45 後更新資料，且最近預期交易日有行情做保守判定。台股休市假日、臨時休市無法靠單純週曆全自動確認；請人工核對。無盤後資料或抓取失敗不給綠燈。
- 瀏覽器通知需 HTTPS 或 localhost 且允許通知；只有**開啟網站**時才會比較新訊號。真正背景推播／手機鎖屏通知須再建置推播伺服器，GitHub Actions 單獨不具備這項能力。
- 沒有接券商下單、沒有自動交易，僅作研究。

## 每日標準作業

18:30 後確認 Actions 成功 → 開啟網頁按「更新行情」→ 查閱收盤資料日期／訊號排行 → 打開 K 線比對重要支撐、量價與風報比 → 人工核對朱老師規則 → 自行決定是否進場。
